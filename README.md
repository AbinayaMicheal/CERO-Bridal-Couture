# CERO Bridal Couture

**CERO Bridal Couture** is a full-stack bridal e-commerce web application designed to provide a personalized shopping experience for brides. Users can explore bridal collections, view product details, customize their preferences, and manage their shopping experience.

## Features

- User Registration and Login
- Firebase Authentication
- Browse Bridal Collections
- Filter Products by Category
- View Detailed Product Information
- Add Products to Cart
- Add Products to Wishlist
- Customize Bridal Outfits
- User Profile Management
- Responsive User Interface

## Technologies Used

**Frontend**
- React.js
- Tailwind CSS
- JavaScript
- Axios
- React Router DOM

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB Atlas
- Mongoose

**Authentication**
- Firebase Authentication

## Installation and Setup

### 1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL


### 2. Navigate to the Project


cd cero-bridal-couture


### 3. Install Frontend Dependencies

cd cero-bridal-couture
npm install


### 4. Start Frontend


npm run dev


### 5. Install Backend Dependencies

Open another terminal:

cd backend
npm install


### 6. Start Backend

npm start


## Environment Variables

Configure the required environment variables for Firebase, MongoDB Atlas, and other integrations before running the application.

Do not upload `.env` files or private credentials to GitHub.
